# 🚴‍♂️ 鹈鹕骑单车 (Pelican on a Bicycle)

一个充满趣味与精致动画的纯前端网页互动应用：一只戴着骑行帽与潮流墨镜的大嘴鹈鹕正踩着单车在海滨公路飞驰漫游！

> 本项目为 `gemini-3-8-high-codex` 全自主端到端实现的互动趣味网页演示项目。

---

## 🌟 特性一览

- 🚲 **精细矢量动效 (SVG + CSS/JS)**
  - 完整逼真的单车机械结构（飞轮、链条、前后辐条旋转、曲柄脚踏）。
  - 鹈鹕骑手躯干随行起伏、头部摇摆、双腿踩踏连杆连贯拟真联动。
  - 特色大喉囊（Gular pouch）随吞食与叫喊动态扩张膨胀。
- 🐟 **互动小游戏机制**
  - **大嘴接鱼**：骑行中迎面飞跃海鱼，鹈鹕大嘴接中自动吞入喉囊并记录积分。
  - **踩踏加速**：支持点按屏幕/踏板按钮或空格键触发冲刺提速。
  - **5档变速齿轮**：支持从 1 档“悠闲漫骑”自由切换至 5 档“极限风暴”。
- 🔔 **纯 Web Audio 交互音效**
  - 零外部音频资源依赖，内置算法级清脆复古自行车铃音（Ding-Dong）、鹈鹕原声嘎嘎叫鸣笛、加速风阻与吞鱼音效。
- 🌅 **昼夜三景动态切换**
  - 支持白昼海岸 ☀️、落日晚霞 🌇 与静谧星夜 🌌 无缝切换，海浪微澜、灯塔闪烁、棕榈树与路灯迎风飞驰。
- 📱 **响应式与全键盘支持**
  - 兼容移动端与桌面端，提供快捷键操作支持（`Space` 加速、`B` 车铃、`Q` 叫喊、`G` 墨镜、`T` 昼夜、`1-5` 档位）。

---

## 🎮 操作指南

| 操作 / 快捷键 | 功能说明 |
| :--- | :--- |
| **Space** / 点击视口 / 踩脚踏按钮 | 踩脚踏加速冲刺 |
| **B** / 车铃按钮 / 点击车把铃铛 | 响铃音效 (Ding-Dong) |
| **Q** / 嘎嘎叫按钮 | 鹈鹕喉囊鸣叫 |
| **G** / 墨镜按钮 | 佩戴 / 摘下骑行潮流墨镜 |
| **T** / 昼夜按钮 | 切换 白昼 / 落日 / 星夜 场景 |
| **1 ~ 5 数字键** / 滑块 | 切换单车变速箱档位 (1-5 档) |

---

## 🚀 运行方式

本项目采用纯原生 HTML5 / CSS3 / Vanilla JavaScript 构建，无需任何构建工具或额外依赖。

直接在浏览器中打开 `index.html` 即可体验：

```bash
# 启动本地轻量静态服务（可选）
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```
